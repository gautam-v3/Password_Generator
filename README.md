# 🔐 Password Generator

A customizable, cryptographically secure command-line password generator written in Python.

---

## 🚀 Features

- **Cryptographically Secure**: Built with Python's `secrets` module instead of pseudo-random generators.
- **Customizable Composition**: Explicitly choose the exact number of letters, digits, and special characters.
- **Input Validation**: Safely handles invalid inputs and negative values without crashing.
- **Zero Dependencies**: Uses only the Python standard library—no external packages needed.

---

## 📋 Prerequisites

- Python 3.8 or higher installed on your system.

---

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/gautam-v3/Password_Generator.git](https://github.com/gautam-v3/Password_Generator.git)
   cd Password_Generator
   ```

2. **Run the script:**
   ```bash
   python password_gen.py
   ```
